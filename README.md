## 🏗️ Engineering Architecture Standard

Every project added to this repository follows a strict decoupled engineering standard:
* **`/backend`**: Houses the predictive engines, data processors, trained serialized models (`.pkl`), and Flask API endpoints.
* **`/frontend`**: Houses the client-side user interface (HTML5 canvas/forms, CSS3 layouts, and Vanilla JavaScript Async Fetch API).
